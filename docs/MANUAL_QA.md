# Manual QA · Milestone 10b

Use Node 22.12+, `npm ci`, `npm run dev`. For production run `npm run build` and `npm run preview`; `npm run test:smoke` serves `dist` under `/garden/` and checks the actual relative-path output with Chromium. Browser tests use a development-only Playwright dependency. This environment supplies `/usr/bin/chromium`; on another machine run `npx playwright install chromium` or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

- Start with a fresh origin. Four dismissible hints appear; reload keeps their dismissal. Debug editors/raw state/gallery are hidden until the Debug button or backtick. Help explains genes, skills, parts, bonds and competitions.
- Pause with Space, choose speeds with1–4, use Escape to deselect. Focus the habitat and use Tab/Shift+Tab to cycle Derbils. Outside the habitat, Tab moves through real buttons/forms. Enter activates them. Verify focus remains visible.
- Select a Derbil by canvas and by the HTML roster. Its derived name/stage/thought, needs, six skills, trophies and cosmetic appear. Open Relationships and Breeding & family / lineage from the card. Pair/Block must retain willingness, stage and kinship reasons.
- Create each competition format; choose stock-backed prizes and observe inventory escrow, voluntary entry, rankings, award descriptions and exact cancellation refunds. Try an invalid prize quantity and inspect the error.
- Save while paused, reload and compare the exact tick/competition state. Export and import the same file; review the population/tick confirmation. Cancel an import and verify the old world remains. Open “World, settings & help” for import/export, New Game and settings. New game offers an optional seed, export-first checkbox and explicit confirmation.
- With a slow save in flight, import or start a seeded world. Replacement controls freeze until completion; reload must retain the replacement. Headless delayed-codec/publication tests also verify that runtime recovery cancels pending autosaves.
- IndexedDB database `creature-habitat-checkpoints`, store `saves`, holds the revision pointer `<legacy key>.current` and immutable slots. Corrupt the newest slot: Load recovers the previous valid revision and offers a broken-payload download. Corrupt all referenced slots: data stays present, progression stops and New Game/download are offered. Restore the exported file afterward.
- Simulate QuotaExceededError using a storage stub (headless tests cover each write stage). The current verified pointer must survive and the UI must offer Export. Test IndexedDB-disabled/localStorage fallback separately if your browser supports that setting.
- Open two tabs in the same browser profile. Second is read-only/paused and can inspect/export. Take over transfers control and pauses the first. Saving from a stale writer must be refused. Close/reload the owner and verify it can reacquire ownership.
- Set a valid exported envelope timestamp two hours earlier (recompute checksum, as the smoke fixture does), with speed1, then import/reopen. Observe catch-up progress, Skip and the return summary. A paused saved game advances zero. Hide/resume without counting time twice. No drawing or saving occurs during replay except its durable source/finished boundary.
- Inject an exception in `safeAdvance` during development. The error panel must show seed, last good tick, command history and copyable details. Verify the last autosave is byte-for-byte unchanged; try Export Current State and Restore Last Save.
- Change reduced motion, overlays, text size and high contrast. Reload; settings persist separately. Reset settings and confirm the world remains. Verify affinity has solid/dashed cues as well as color and the journal aria-live announcements are throttled.
- Check390px and desktop layouts, browser zoom, resize and different device pixel ratios. Run the appearance benchmark and import the validated30-Derbil/all-parts fixture produced by `node scripts/browser-fixture.mjs` for frame measurements. Repeat with reduced motion and debug hidden.
- Confirm no browser console errors/warnings in normal play and no missing assets from a static subfolder. Save/export downloads should remain JSON, never interpreted markup.

Automated smoke coverage and measured results are recorded in BALANCE_LOG.md / DECISIONS.md after the final run. These manual checks also cover interactive controls not included in the compact smoke test.

Verify selection, competitions, save/reload, Export/Import and a second tab.
