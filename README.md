# Creature playable preview

Download Creature.zip, extract it, and open Creature/Creature.html in Chrome or Edge. No installation or coding is needed.

Click a creature to inspect it. Space pauses; keys1–4 change speed. Use World, settings & help > Export for a portable world backup.

This is a work-in-progress preview, not the final verified Milestone10b release. Basic browser selection, competition creation and save/reload passed. Full balancing, full regression tests and the full soak are unfinished.
